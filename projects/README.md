# 项目目录

[返回仓库首页](../README.md)

每个任务单独维护代码、说明、技术报告和计算产物。请选择研究方向：

| 编号 | 项目 | 核心问题 |
|---|---|---|
| 01 | [先导可开发性](task01_lead_developability/) | 候选结构的可开发性指标与适用边界是什么？ |
| 02 | [靶向蛋白降解](task02_tpd/) | 三元复合物、连接子和降解动力学如何相互影响？ |
| 03 | [共价抑制剂](task03_covalent_kinetics/) | 失活、恢复、驻留时间和反应性如何表征？ |
| 04 | [PBPK](task04_pbpk/) | 给药量如何转化为随时间变化的组织暴露？ |
| 05 | [CYP DDI](task05_cyp_ddi/) | 抑制与酶周转如何改变探针暴露？ |
| 06 | [ASD 制剂](task06_asd/) | 载药量与聚合物假设如何影响过饱和和析晶？ |
| 07 | [肿瘤免疫 QSP](task07_qsp/) | 假设机制下组合给药产生怎样的动态响应？ |

各目录中的 `README.md` 提供运行方式和报告、数据、图表入口；任务 5–7 的原始需求保存在各自 `TASK.md`。统一测试位于仓库 [tests](../tests/)，历史计算与整改记录位于 [docs](../docs/)。
